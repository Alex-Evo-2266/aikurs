# Мои задачи

Простое веб-приложение для ведения списка задач. Создано на React, TypeScript и Vite с использованием Tailwind CSS.

## Возможности

- **Список задач** — у каждой задачи есть название, описание, дата создания и статус
- **Статусы** — «Новая», «В работе», «Выполнена» — статус можно менять в один клик
- **Добавление / редактирование / удаление** — полный набор операций с задачами
- **Фильтрация** — просмотр всех задач или только задач с определённым статусом
- **Валидация** — нельзя создать задачу без названия; показывается понятное сообщение
- **Подтверждение удаления** — задача не удаляется случайно, требуется подтверждение
- **Локальное сохранение** — задачи хранятся в localStorage и не пропадают после перезагрузки
- **Адаптивный дизайн** — удобно пользоваться как на компьютере, так и на телефоне

## Запуск локально

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать проект для продакшена
npm run build

# Проверить типы
npm run typecheck
```

После запуска `npm run dev` откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

## Структура проекта

```
src/
  types.ts              — типы и константы (статусы, фильтры)
  hooks/
    useTasks.ts         — хук для управления задачами + localStorage
  components/
    TaskForm.tsx        — форма добавления/редактирования задачи
    TaskItem.tsx        — карточка отдельной задачи
    TaskList.tsx        — список задач
    FilterBar.tsx       — панель фильтрации + выбор статуса
    ConfirmDialog.tsx   — модальное окно подтверждения удаления
    EmptyState.tsx      — заглушка для пустого списка
  App.tsx               — корневой компонент, связывает всё вместе
  main.tsx              — точка входа
```

## Технологии

- React 18 + TypeScript
- Vite — сборщик и dev-сервер
- Tailwind CSS — стилизация
- lucide-react — иконки
